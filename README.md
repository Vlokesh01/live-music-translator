## 🧠 How the Local Translation Works

live-music-translator uses Gemma, a family of language models, together with LiteRT-LM, a lightweight runtime that lets those models run efficiently on ordinary computers. Because both parts run locally, the translation is generated on your own device.

This local approach has a few practical benefits:

- Your listening habits and lyric content are not sent to an external translation service.
- The app keeps working the same way whether or not you have a stable connection after setup.
- Response times are predictable because the model runs on hardware you control.
- You can use the app in situations where sending audio or text to a remote server would not be appropriate.

The app is focused on one task: turning lyric lines into readable translations as the song plays.
